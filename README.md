# PersonaTalk

PersonaTalk e um aplicativo local inspirado em apps de personagens de IA. Ele permite criar varios personagens para conversar sobre namoro, amizade, conflitos, autoestima e temas livres.

## Recursos

- Conversa com personagens configuraveis.
- Criacao de varias personas do usuario.
- Memoria local para fatos importantes.
- Aprendizado simples a partir de frases como "meu nome e", "eu gosto de" e "eu nao gosto de".
- Exportacao e importacao de backup em JSON.
- Funciona sem servidor e sem dependencias externas.

## Como usar

Abra `index.html` no navegador.

Os dados ficam salvos no `localStorage` do navegador. Use o botao de exportar para guardar um backup.
